An M3U playlist is a plain-text file listing live TV stream URLs. Free, public IPTV playlists contain channels that broadcasters make publicly available online - news, public television and similar streams. You open the .m3u file in a player like VLC, Kodi or TiviMate to watch the channels.

The channels come from the open-source iptv-org project, which indexes only streams that broadcasters publish openly. Most are news, public, government or sports channels that stream freely. Legality can vary by country, so you are responsible for compliance with local copyright law. Streams are not hosted on our servers.

On desktop, open the .m3u file in VLC (Media, Open File) or add it as an IPTV source in Kodi. On mobile, use IPTV Smarters, GSE Smart IPTV, TiviMate or Televizo and load the file or paste the copied playlist text.

Public IPTV streams are maintained by individual broadcasters, not by us, so they can go offline, change URL or be geo-blocked. iptv-org itself no longer checks whether streams are live, so we run our own automatic health check and prefer verified-working streams.
